## 처음 실행하는 법
1. 받은 압축파일을 오른쪽 버튼 → **[모두 압축 풀기]**
2. 바로캡처 폴더를 문서 폴더처럼 지우지 않을 곳에 두기
3. **바로캡처.exe** 두 번 누르기 (파일 끝 글자가 숨겨진 PC에서는 "바로캡처"로 보여요. 종류가 "응용 프로그램"인 것)
4. 파란 창 "Windows의 PC 보호"가 뜨면 **[추가 정보] → [실행]** (처음 한 번만)
5. 처음 화면에서 캡처 키를 고르고 한 번 눌러 "잘 돼요!" 확인

## 이미 받으신 분: 새 버전으로 바꾸기
1. 시계 옆 바로캡처 아이콘 오른쪽 클릭 → **[종료]**
2. 새 zip 안의 **바로캡처.exe**를 예전 바로캡처 폴더에 넣고 **덮어쓰기**
3. 다시 켜기 (설정과 캡처는 그대로 남아요)

## 쓰는 법
- PrtSc → 드래그: 찍고 바로 복사, Ctrl+V로 붙여넣기
- PrtSc → Enter: 전체 화면 / PrtSc → S: 스크롤 캡처 (끝까지 내려간 뒤 "띠링" 소리가 날 때까지 몇 초 기다리기)
- 자세한 사용법은 압축파일 안의 **바로캡처_사용안내.pdf**
